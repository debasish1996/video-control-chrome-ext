# Privacy Policy – Fullscreen Video Controls

Effective date: 2026-03-28

Fullscreen Video Controls does **not** collect, store, transmit, or sell personal data.

## What the extension does

- Adds a local control panel for HTML5 video playback on the active tab when the user clicks the extension.
- Reads and updates video playback state (for example, current time, play/pause) only in the page currently being controlled.

## Data handling

- No account creation
- No analytics
- No tracking identifiers
- No remote code
- No data sent to external servers

## Permissions used

- `activeTab`: allows the extension to run on the tab the user explicitly interacts with.
- `scripting`: injects local extension scripts/styles into the active tab on demand.
